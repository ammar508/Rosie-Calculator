# AGENTS.md

## Principles
- One friendly public page for a local dog-walking business; the instant quote calculator is the heart of it, serving both the owner and her customers.

## Constraints
- Single-file web app: one HTML file with embedded CSS and JS. No backend, no database, no login, no external API calls, no frameworks.

## Definition of done
- Opens from disk in a browser with no build step; quote updates instantly and correctly, on phone and desktop, with no console errors.
